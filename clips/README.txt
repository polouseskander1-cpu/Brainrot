Put the clips you want turned into reels here (podcast moments, educational videos, interviews...).

Make one subfolder per show / topic and drop clips inside, for example:

    clips/
      my_podcast_ep12/
        clip1.mp4
        clip2.mp4
        clip1.txt        <- optional: a title shown at the start of clip1's reel
        title.txt        <- optional: a title for every clip in this folder

The bot notices new subfolders and new clips by itself. Each clip becomes one reel in the
output folder, with the same subfolder name. Clips can be any length (1-5 minutes is ideal).
Folders and files starting with _ or . are ignored (handy for an _archive folder).
